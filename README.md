# react-movie-lab

A React app for browsing movies, TV shows and people, using data from [TMDB](https://www.themoviedb.org/).

Built with React.

## Video demo

The video is here: [Link](https://drive.google.com/file/d/1_4a8m2Vb5XYxhKN0avZ-vXdiMHWY9TlA/view?usp=sharing).

There is a Camtasia watermark, but the app itself is still visible.

## Running it

1. Get a TMDB API key.
2. In the `movies` folder, create a `.env` file with:
   ```
   VITE_TMDB_KEY=your_key_here
   ```
3. Install and start:
   ```
   cd movies
   npm install
   npm run dev
   ```
4. Open http://localhost:5173
